# SNOWPACK Profile Reader

A hardware-adaptive Python reader for SNOWPACK `.pro` files using `xarray`.

This tool provides a flexible and efficient way to parse, process, and analyze snowpack profile data generated by the [SNOWPACK](https://models.slf.ch/p/snowpack/) model. It automatically leverages your available hardware — using GPU acceleration with CuPy when available, or falling back to NumPy on CPU.

## 🚀 Features

- Parse station metadata and profile time series from SNOWPACK `.pro` files.
- Store data as an `xarray.Dataset` with seamless CPU/GPU backend.
- Vectorized calculation of critical snowpack metrics, including `rc_flat`.
- Analyze specific snowpack sections (e.g., slabs above weak layers).
- Flexible summarization of profiles with built-in or custom statistics.
- GPU acceleration with fallback to CPU if GPU is unavailable.

## 🔧 Hardware Acceleration

- ✅ **GPU Support:** Automatically uses an NVIDIA GPU if available. Requires:
  - [`cupy`](https://docs.cupy.dev/en/stable/install.html) installed (`pip install cupy-cuda12x`)
  - CUDA drivers and toolkit installed on your system.

- 💻 **CPU Fallback:** Falls back to NumPy if no GPU is detected.

The array backend is automatically selected and abstracted as `xp` in the code, so users don't have to worry about switching between CPU and GPU.

## 📄 Example Usage

```python
from snowpack_reader import SnowpackProfile

# Load a SNOWPACK .pro file
reader = SnowpackProfile('path/to/your/file.pro')

# Print basic info
print(reader)

# Extract a single profile to a pandas DataFrame
df = reader.profile_to_dataframe('2025-02-15 12:00:00')
print(df)

# Get daily summary statistics
summary = reader.get_profile_summary(
    parameters_to_calculate={
        'rc_flat-min': ('rc_flat', 'min'),
        'density-weighted_mean': ('density', 'weighted_mean')
    },
    start_date='2025-02-01',
    end_date='2025-02-28'
)
print(summary)
```

## ⚙️ Typical Workflow

1. Load a `.pro` file using `SnowpackProfile`.
2. Access parsed snowpack data as an `xarray.Dataset` through `.data`.
3. Extract specific profiles (`profile_to_dataframe()`) or generate daily summaries (`get_profile_summary()`).
4. Perform slab analysis, weak layer tracking, or any other snowpack-related investigation.

---

## 📚 Documentation

- The main class is `SnowpackProfile`.
- Parsed data is stored in `.data` as an `xarray.Dataset`.
- Station metadata (e.g., latitude, altitude) is available via `.metadata`.
- Data arrays are backed by either NumPy (CPU) or CuPy (GPU), abstracted as `xp`.
